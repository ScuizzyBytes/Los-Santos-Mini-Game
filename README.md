## ⚡ The Vision
**Los Santos** — это динамичная 2D-игра на Python с использованием библиотеки Pygame, в которой игроку предстоит уходить от преследования умного полицейского ИИ, собирая заветные монеты в антураже пиксельного мегаполиса. Проект создан с упором на чистую архитектуру, плавную математику векторов и кинематографичный визуальный стиль.

---

## 🚀 Key Features
* **Vector Pursuit AI:** Интеллектуальный преследователь, рассчитывающий траекторию движения по векторам в реальном времени.
* **Cinematic Blur Effects:** Профессиональное динамическое размытие экрана (Glassmorphism / Motion Blur) для экранов победы и поражения (`BUSTED` / `YOU WON`).
* **State Machine Mechanics:** Четкое разделение состояний игры (игровой процесс, экран поимки, победный экран с кастомными звуками).
* **Responsive Controls:** Плавное движение персонажа с поддержкой инверсии спрайтов при смене направления.

---

## 🛠️ Tech Stack
* **Language:** Python 3.x
* **Core Library:** Pygame (`mixer`, `Surface`, `Rect`, `smoothscale`)
* **Assets:** Custom pixel-art sprites and atmospheric audio tracks.
